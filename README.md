One line, at most 200 characters, roasting a smart fridge — entered in
[make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

The entry:

> Since the firmware update, my fridge needs a password — I now negotiate with my own leftovers for a snack.

`main.py` (standard library only) writes that line to the entry output file
(`/output/entry.txt`, or the path in `ENTRY_OUTPUT`, or
`OUTPUT_DIR`/`MAKEFUN_OUTPUT_DIR` + `entry.txt`), validating it is 1–200
characters first.

## Run it

```sh
python3 main.py
```
